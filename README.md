# DMD Costs legal costs tools (MCP server)

Free, read-only legal costs tools for **England and Wales**, built for AI assistants. A remote MCP server (Streamable HTTP) run by [DMD Costs](https://www.dmdcosts.co.uk), law costs draftsmen in Westhoughton, Bolton.

- **MCP endpoint:** `https://www.dmdcosts.co.uk/mcp`. No key and no sign-up.
- **REST API:** `https://www.dmdcosts.co.uk/api/tools`, documented in OpenAPI at `https://www.dmdcosts.co.uk/openapi.json`.
- **Every tool, for people:** [dmdcosts.co.uk/legal-costs-help](https://www.dmdcosts.co.uk/legal-costs-help).

39 tools, server version 1.16.0. Each tool runs the same code as its page on dmdcosts.co.uk. Every answer comes back as structured data and as plain text an assistant can quote, with a link to the page and the date the rules were last checked.

## Connect

**Claude** (claude.ai or Claude Desktop): Settings → Connectors → Add custom connector, then enter the URL `https://www.dmdcosts.co.uk/mcp`. No authentication is needed.

**Claude Code:**

```bash
claude mcp add --transport http dmd-costs https://www.dmdcosts.co.uk/mcp
```

**Cursor** (`.cursor/mcp.json`) and other clients that use the `mcpServers` format:

```json
{ "mcpServers": { "dmd-costs": { "url": "https://www.dmdcosts.co.uk/mcp" } } }
```

**VS Code** (`.vscode/mcp.json`):

```json
{ "servers": { "dmd-costs": { "type": "http", "url": "https://www.dmdcosts.co.uk/mcp" } } }
```

**ChatGPT:** where your plan allows custom connectors, add a connector with the URL `https://www.dmdcosts.co.uk/mcp` and no authentication. A GPT or another tool that uses OpenAPI actions can import `https://www.dmdcosts.co.uk/openapi.json` instead.

**VS Code, in one click:** [Install in VS Code](https://vscode.dev/redirect/mcp/install?name=dmd-costs&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fwww.dmdcosts.co.uk%2Fmcp%22%7D).

**Claude Code plugin.** This repository is also a plugin marketplace. The plugin adds the server and a skill that tells Claude when to use these tools for costs questions:

```text
/plugin marketplace add Ments123/dmd-costs-mcp
/plugin install dmd-costs@dmd-costs
```

**Gemini CLI extension:**

```bash
gemini extensions install https://github.com/Ments123/dmd-costs-mcp
```

## How it behaves

- **Read-only.** Every tool is annotated `readOnlyHint: true` and `destructiveHint: false`. Nothing is written or sent anywhere.
- **Stateless.** Inputs are used to work out the answer and are not stored by the tools.
- **Sourced.** Answers name the rule, practice direction or statute they apply, and link to the page that explains it.
- **The court-form builders stay in the browser.** The N252, N254, N258, N260 and other form builders on dmdcosts.co.uk run in the user's browser, so case details never reach the server, and they are not part of this server.

## Privacy

The tools keep no record of what you ask. The hosting provider's standard request logs may record request metadata, such as the time and IP address, for security. Privacy policy: [dmdcosts.co.uk/privacy-policy](https://www.dmdcosts.co.uk/privacy-policy).
